Buttons & Actions

Native HTML representation of button elements, states, and interaction styles.

Primary Button

The main call-to-action submit button style used in forms. Dark gray background with uppercase tracking.

Secondary Button

White button with gray border and shadow. Used for secondary actions like "Cancel" or "Back".

Danger Button

Red background button for destructive actions such as deleting records or terminating accounts.

Icon Button

Small square or circular button designed to wrap icons in data tables or toolbars.

Link Button

A button element styled as an underlined text link. Ideal for inline form submission toggles.

Button Link

An anchor tag (<a href="#">) styled to look like a button.
