01. React Overview & Architecture

1. Introduction to React 19

React is a popular open-source JavaScript library developed by Meta for building user interfaces based on components. Modern React (v19+) introduces React Server Components (RSC), Server Actions, the React Compiler (automatic memoization), and new hooks (use, useActionState, useFormStatus, useOptimistic).

Core Highlights

- **Declarative Paradigm**: Define UI states; React automatically updates and renders the right components when data changes. - **Component-Driven**: Build isolated, reusable components that manage their own state and compose them to make complex UIs. - **Virtual DOM & Fiber Engine**: Fiber architecture breaks rendering work into incremental units for fluid 60/120fps UI responsiveness. - **React Server Components (RSC)**: Execute components on the server to reduce client bundle size and fetch data zero-waterfall. - **Automatic Memoization (React Compiler)**: Eliminates manual useMemo and useCallback boilerplate across codebases. ---

2. Component Mental Model & Data Flow

Data in React flows **unidirectionally** (top-down) from parent to child via props. 

                   +------------------------+
                   |    Parent Component    |
                   |   (Holds State: data)  |
                   +-----------+------------+
                               |
                               | (passes props)
                               v
                   +-----------+------------+
                   |    Child Component     |
                   |   (Receives Props)     |
                   +------------------------+
