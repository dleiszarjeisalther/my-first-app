HOW TO PREVENT DOUBLE-CLICKING / SPAM SUBMISSIONS IN LARAVEL

Whenever you create a new form in the future, follow these two steps to ensure users cannot click the "Submit" button multiple times.

=======================================================
STEP 1: UPDATE THE BLADE TEMPLATE (FRONTEND)
=======================================================
We use Alpine.js (which is already included in this project) to track when the form is submitting.

1. Find your <form> tag and add the Alpine.js state tracking:
   Change this:
   <form action="{{ route('example.store') }}" method="POST">
   
   To this:
   <form action="{{ route('example.store') }}" method="POST" x-data="{ submitting: false }" @submit="submitting = true">

2. Find your submit <button> and add the dynamic disabled attributes:
   Change this:
   <button type="submit" class="bg-blue-500 text-white ...">Submit</button>

   To this:
   <button type="submit" :disabled="submitting" :class="{ 'opacity-50 cursor-not-allowed': submitting }" class="bg-blue-500 text-white transition-all ...">Submit</button>

   * What this does: When the form is submitted, `submitting` becomes true. The button instantly becomes unclickable and visually dims out.

[SPECIAL CASE: MULTIPLE SUBMIT BUTTONS]
If your form has multiple submit buttons that send different values (e.g., "Save & Go Back" vs "Save & Continue"), disabling the button exactly on submit might prevent the browser from sending that button's value to the backend.
In that case, do this:
1. Form tag: <form action="..." method="POST" x-data="{ submitting: false, redirectTo: '' }" @submit="submitting = true">
2. Add hidden input inside form: <input type="hidden" name="redirect_to" :value="redirectTo">
3. Update buttons to set the value on click: <button type="submit" @click="redirectTo = 'go_back'" :disabled="submitting" ...>Save & Go Back</button>


=======================================================
STEP 2: UPDATE THE CONTROLLER (BACKEND)
=======================================================
Even with the frontend disabled, advanced users might use scripts to bypass the browser. Always back it up with Laravel's Rate Limiting (Throttle) middleware.

In your Controller, add the `HasMiddleware` interface and use the `throttle` middleware:

    namespace App\Http\Controllers;
    
    use Illuminate\Routing\Controllers\HasMiddleware;
    use Illuminate\Routing\Controllers\Middleware;

    class ExampleController extends Controller implements HasMiddleware
    {
        public static function middleware(): array
        {
            return [
                // Limits the user to 2 requests per minute on the store method
                new Middleware('throttle:2,1', only: ['store']),
            ];
        }
        
        // ...
    }


=======================================================
STEP 3: REBUILD ASSETS (IF NEEDED)
=======================================================
If you added new Tailwind CSS classes like 'opacity-50' or 'cursor-not-allowed' for the very first time in a new file, remember to run the build command so Tailwind can generate the CSS for them:

    npm run build
